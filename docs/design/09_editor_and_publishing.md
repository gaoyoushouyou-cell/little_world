# 09 エディタ・セーブ・公開

## 2種類のエディタ

| | 作者エディタ | 自分の夢（閲覧者用） |
|---|---|---|
| 使う人 | ユーザー（作者）と Claude | 公開版を遊ぶ人 |
| 動く場所 | ローカルの開発サーバーのみ | 公開版のブラウザの中 |
| 保存先 | `content/` のファイル（原本） | localStorage（JSON で書き出し・読み込みも可） |
| 見える範囲 | 全エリア・全種（ネタバレあり） | 自分が作ったものだけ |
| 空間 | 本編の地図 | **本編とは別の空間**。本編の地図や未訪問の情報には触れない |

本編と「自分の夢」を分けることで、次の矛盾を防ぐ。

- 閲覧者がエディタで本編の全体を見てネタバレになる
- 閲覧者が虚無に作った場所と、作者があとで追加するエリアが重なる

## 作者エディタ

- **地図エディタ**：[08_map.md](08_map.md)
- **エリアエディタ**：タイルの配置、パレットからのドラッグ＆ドロップ、範囲選択、住人や物の配置、プロパティの編集
- UI はゲーム画面の上に重ねた HTML（Preact）
- 保存：Vite 開発サーバーに保存用の口を足し、`content/` の JSON に直接書き込む
- 保存されたファイルを Claude も読めるので、ユーザーの編集の続きを Claude が作れる

## 種（未生成エリア）の流れ

1. ユーザーが地図エディタで虚無をドラッグして範囲を指定する
2. タイルや部品を置いたり、メモ（例：「ここは学校の廊下が無限に続く」）を貼ったりする
3. `content/seeds/<id>.json` に保存される
4. チャットで「種を育てて」と言うと、Claude が種を読んでエリアの中身を作る
5. 作ったら `validate` と `reachability` を実行して報告する

## セーブデータ

- 進行（取得済みのかけら、解放したエフェクト、mood、フラグ、実績、所持品、拠点、上書き層）を保存
- 公開版は localStorage。ブラウザのデータを消すと進行も消えるので、**書き出し・読み込み**機能を付ける
- **セーブには版番号を付け、移行処理を用意する**（世界が育っても古いセーブが壊れない）
- 中身はすべて ID で参照する。ID は変えない・消さない

## 公開（GitHub Pages）

- `.github/workflows/deploy.yml` で push 時に自動ビルド・公開
- 公開版は静的サイトなので、作者エディタ（ファイル保存）は含めない
- 公開版では閲覧者の操作の記録（テレメトリ）を取らない
- 秘密情報（API キーなど）をリポジトリに含めない
- フォント・音・画像は再配布できるライセンスのものだけ。ライセンス表記を同梱
