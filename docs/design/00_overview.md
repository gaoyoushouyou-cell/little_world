# 00 概要

## コンセプト

- Terraria のような **16px タイルのドット絵**で表現された世界
- ゆめにっきのような **乱雑で意味の分からない夢の世界**を歩く
- 世界は **エリアの集まり**。端で隣り合うか、ワープでつながる
- エリアごとに **視点（横 / 見下ろし）と物理条件**を変えられる
- 背景はレイヤーに分け、**パララックスで壮観な眺め**を作る
- 世界は遊ぶ人と作る人（ユーザーと Claude Code）で **育て続ける**
- 自分のパソコンで遊びつつ、**GitHub で公開**する

## 体験の柱

1. **眺めてゆっくりする** — 静かな景色、漂う粒子、環境音。浅い夢には罰がない
2. **意味も分からないまま追いかけられる** — バックルームのような不安。理由を説明しない存在、ねじれた空間
3. **集めて開く** — 夢のかけらを集め、エフェクトを解放し、届かなかった場所へ戻る（メトロイドヴァニア型）
4. **深く潜って持ち帰る** — 深い夢ほど良い素材と多くのかけら。ただし失う危険もある
5. **夢に住みつく** — 莫大な素材で、エリアを拠点に変える
6. **世界を育てる** — チャットで世界観を伝えると Claude がエリアを作り、虚無にはエディタで種を植える

## 「夢らしさ」と「使いやすさ」の線引き

- **仕組み**（持ち物、拠点、エフェクトの木、地図）は明快に見せる
- **夢の中身**（住人や追跡者の規則、mood の意味、出来事の理由）は説明しない
- 夢日記の文章は、事実ではなく印象を書く

## 技術スタック

| 項目 | 選定 | 理由 |
|---|---|---|
| 言語・ビルド | TypeScript + Vite | 型でデータの誤りを検出。ホットリロードが速い |
| ゲーム本体 | Phaser（最新安定版） | パララックス、カメラ、WebGL 描画、音、シーン |
| 物理 | 自作の軽量な矩形判定 | エリアごとに重力の向き・摩擦・時間の速さを自由に変えるため |
| 画面に重ねる UI | Preact + ドット調の CSS | メニューやエディタは DOM のほうが作りやすく、アクセシビリティツリーで自動検査できる |
| データ検証 | zod | すべての JSON をスキーマで検証し、型もそこから作る |
| ローカル保存 | Vite 開発サーバーに保存用の口を足す | エディタの操作が `content/` のファイルに直接書き込まれる |
| 音 | Web Audio による合成音 | コードで定義でき、ライセンスの心配がない |
| 公開 | GitHub Pages + GitHub Actions | push で自動ビルド・公開 |

- タイル：**16px**（決定）
- 内部解像度：**480×270 を整数倍に拡大**（推奨・仮）。`imageSmoothingEnabled = false`
- ドット絵：パレット + 文字グリッドの JSON（Claude が書ける形式）。手描きの PNG も取り込める

| 58 | 持ち物の強化 | 並べ替え・まとめる・半分に分ける・説明・重さの合計・近くの倉庫にまとめて入れる |

## 公開にあたっての方針

- 「バックルーム」は元ネタとして参照するだけ。特定の作品のキャラクターや画像は使わず、オリジナルの存在を作る
- フォント・音・画像は再配布できるライセンスのものだけを使い、ライセンス表記を同梱する
- 公開リポジトリには API キーなどの秘密情報を含めない
