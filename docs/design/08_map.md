# 08 地図

## データ

- `content/world/map.json`：エリアの位置・ワープ・種だけを書く（地図の骨組み）
- `content/areas/*/`：各エリアの中身

骨組みと中身を分けることで、地図の編集と中身の作成がぶつからず、読むときも軽い。

```jsonc
// content/world/map.json（イメージ）
{
  "areas": [
    { "id": "bed_room", "pos": [0, 0] },
    { "id": "inverted_aquarium", "pos": [30, -10] }
  ],
  "warps": [
    { "from": { "area": "bed_room", "at": [5, 8] },
      "to":   { "area": "endless_corridor", "at": [2, 2] },
      "bidirectional": false }
  ],
  "seeds": ["seed_school_corridor"]
}
```

- 地図は1枚の大きな座標平面。エリアは **実際のタイル数どおりの大きさの四角**
- 接している辺が自動的に通路になる（[01_world_and_areas.md](01_world_and_areas.md)）

## プレイヤーが見る地図（モザイク表示）

- **作り方**：エリアのタイル層を縮小し、**4×4 タイルを1マス**にまとめ、その範囲で一番多い色をそのマスの色にする。訪れたときに作って保存する
- 描くのは **原本の基本のタイルだけ**（mood で現れる橋などは描かない）
- 揺らぎ区域は **ノイズ模様**、拠点は **印** で表す
- **到達したエリアだけ表示**。未訪問エリアの情報（形・かけらの数など）は一切見せない
- 訪れたエリアには **未取得のかけら数**を表示（`◇ 1/3` = 未取得 / そのエリアの総数）
- **ワープの線**は一度通ってから表示（一方通行は矢印、双方向は両矢印）
- **拠点間ワープの線**は、夢のワープとは別の見た目
- **ループする端**は辺に記号
- **深さ**は枠の色や暗さで表す
- 横 / 見下ろしは色や枠線で区別
- **重なったエリア**は、重なった部分を切り替えて表示する（階層のように選べる）

## 作者用の地図エディタ（ローカル専用）

全エリアと種を含めてすべて表示する。

| 操作 | 結果 |
|---|---|
| エリアの四角をドラッグ | 移動 |
| 端をドラッグ | 大きさを変更 |
| 何もない場所（虚無）をドラッグして範囲を指定 | 新しいエリアの「種」を作る。メモを付ければ Claude が中身を作る |
| 点から点へドラッグ | ワープを作成 |
| エリアをダブルクリック | エリアの編集画面に入る |

- 視点や重力が違うエリアどうしの危険な接続（空中や天井に出る）を警告する
- 保存は開発サーバー経由で `content/world/map.json` と `content/seeds/` に書き込む
