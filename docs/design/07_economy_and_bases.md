## 資源

夢のかけらはエフェクト専用。拠点には別系統の資源を使い、役割を分ける。

| 種類 | 入手方法 | 性質 |
|---|---|---|
| **通貨**（仮称：まどろみ） | 敵を倒す、物を壊す、エリアを探索する | どこでも手に入るが、大量に必要 |
| **素材** | エリアごとに固有（錆、鱗、羽根、ガラスの砂…） | **質**（深いほど高い）と **重さ** を持つ。拠点ごとに必要な素材が違う |

素材の入手先：

1. **揺らぎ区域**での採取（タイルの破壊はここだけ）
2. **戦闘**での撃破
3. **実績**の報酬

- 深いほど質の良い素材が出るが、負ける危険も上がる
- 拠点化に **代償（エフェクトや mood を差し出すなど）は含めない**
- 定義は `content/items/`（通貨・素材）、`content/recipes/`（加工）
- 通貨の見た目は **価値** で使い分ける（決定 43）。安い順に 銅貨 `coin_bronze` → 銀貨 `coin_silver` → 金貨 `coin_gold` → ルーン硬貨 `coin_rune_a/b/c`（仮）。所持量の表示には硬貨の山 `coins_stack_1〜6` を使う

## 拠点化

- 横 / 見下ろしのどちらのエリアでも拠点にできる（`basable: true` のエリア。揺らぎ区域は不可）
- **起点のベッドの部屋は「拠点0」**（無料、最初から所有）

### 流れ
1. 拠点化できるエリアには **拠点の核** がある（例：部屋の中央の、誰も座っていない椅子）
2. 条件（例：そのエリアのかけらを全部取った）を満たしたうえで、資源を払う
3. エリアが変わる：追跡者が消え、狂いが抑えられ、mood を固定できるようになる
4. **建築モード** が使えるようになる（集めた素材でタイルや家具を置く。Terraria の建築に近い）

### 拠点の性質
- **完全な安全地帯**：追跡者は入れない、戦闘はない、何も失わない
- 拠点に着くと **揺れるかけらが確定** する
- 深さの値は残り、素材の質には効く。狂いは抑えられる

### 数と費用
- **上限なし**。ただし n 個目の拠点ほど費用を重くし、多くは作らせない

```
n 個目の拠点の費用 = 基本量 × 成長率^n
必要な素材の質     ≥ 段階 n
```

質の高い素材は深い場所でしか手に入らないので、「どこまで潜れるか」が拠点数の天井になる。
具体的な数値は遊びながら調整する。定義は `content/bases/<area_id>.json`。

### 段階ごとの機能（段階的に強化）
| 段階 | 機能 |
|---|---|
| 1 | ベッド（眠り直しの起点になる）、倉庫 |
| 2 | 拠点どうしのワープ（地図にも、夢のワープとは別の見た目の線で表示）、mood を切り替える装置、夢の回廊への接続 |
| 3 | 日記や実績の展示棚（作業台は段階に関係なく、置けば使える：決定 56） |
| 4 | 住人を招く（友好的になった不自然な住人が住み着く） |

## 建築モードと家具（決定 51〜58）

段階 A〜D の順に作る（A：持ち物の強化・家具・建築モード・上書き層／B：置けるチェスト／C：作業台とレシピ／D：エフェクトの木の配置）。

- **家具は持ち物**（`content/items` の `kind: "furniture"`、`places` に置く物の ID）。重さ 0、1 マスに 1 つ。作る → 持ち物 → 置く → しまうと持ち物に戻る
- **建築モード**：拠点の中で B。画面の下に置ける物の帯が出る
  - 予告はプレイヤーの前のマスに出て、矢印（WASD）で動かす（マウスで指したマスにも動く）。Q / E で置く物を選ぶ（16 マスの格子にそろえる。置けるなら緑、置けないなら赤）
  - Enter / Space で置く、X / Delete で予告の位置の物をしまう、R で左右反転、Esc（または B）で抜ける
  - 置く家具は、手持ちとこの拠点の倉庫（段階2以上なら夢の回廊）から使う。しまった家具は手持ちに入り、いっぱいなら倉庫に入る
- **置けない場所**：拠点の外、エリアの外、壁、ほかの物と重なる（当たり判定のない飾りも足元の列を占める）、出入口・ワープ・出現位置のマス、自分と重なるマス、置くと出現位置から出入口・ワープ・エリアの端の切れ目（隣のエリアへの道）へ歩いて行けなくなるマス（上下左右のマスの探索で、置く前より行けるマスが減るかで判定する）
  - 隣のエリアの当たり判定には、そのエリアに置いた物は入らない（端をまたいだ当たり判定は原本のまま）
- **もとからある物**：`content/objects` の `movable: true`（と `item`）の物だけしまえる。しまうと上書き層で原本を隠す
- **ベッド**：どのベッドで眠っても、そこが目覚める場所になる。拠点の最初のベッド（`movable` でない）はしまえない
- **エフェクトの木**：世界に 1 本だけ。拠点のどこへでも移せる（決定 57）
- セーブの版 2：エリアごとの `placed`（置いた物）と `hidden`（隠した原本の物）

### 置ける箱（段階 B、決定 59〜63）
- 家具「小さな箱」（`chest_small`）。調べる種類は `chest`（`slots` で中身のマス数、既定 18）。中身は置いた物の記録（`placed[].contents`）に持つ
- 開くと手持ちと箱が左右に並ぶ（倉庫と同じ操作。Enter 移す、A 全部しまう、Q 同じ物だけまとめる）
- 中身が空のときだけ建築モードでしまえる
- 拠点の中で持ち物（I）を開いて Q：倉庫と、このエリアに置いた箱すべてへ、すでにある物だけを入れる（Terraria の「近くの箱にまとめて入れる」）
- 作業台ができるまでは、起点の拠点の倉庫に最初から 2 つ入っている（`economy.json` の `starter`。セーブの `granted` で 1 回だけ配る。版 3）
- 箱の中身は拠点の段階上げの支払いには使わない（加工の材料には使う）

### 作業台とレシピ（段階 C、決定 64〜68）
- レシピは `content/recipes/<id>.json`：`output`（できる物と数）、`inputs`（材料・数・最低の質）、`station`（`hand` = 手作り、`workbench` = 作業台）
- **手作り**：どこでも、持ち物の画面かふだんの画面で C。作業台そのものは手作りで作る
- **作業台**：置いた作業台（調べる種類 `workbench`）を調べると、手作りと作業台の両方のレシピが出る
- **材料**：手持ち → 倉庫（段階2以上は夢の回廊）→ このエリアに置いた箱の順に使う。拠点の外では手持ちだけ
- **一覧**：作れる物が上、材料が足りない物は薄く下。選ぶと材料ごとに「持っている数 / 必要な数」
- **質**：素材を作るときは、使った材料のうち一番低い質。家具は 1
- **行き先**：手持ち、いっぱいなら倉庫。入らなければ作らない（材料も減らない）

## 保管（拠点を軸にした仕組み）

### すべての入れ物を同じ「容器」として扱う
手持ち、拠点の倉庫、家具の箱は同じ型。容器ごとに次を持つ。

- 容量（マス数、または重さの上限）
- 受け入れる物の条件（素材だけ、深さ5以上の素材だけ、など）
- ほかの容器とのつながり

新しい種類の容器（例：荷物を運ぶ鳥の住人）は設定ファイルを足すだけで作れる。

### 3段の構成
```
[手持ち]  少ない枠。探索に持ち出す。深いエリアでは沈みのための重りにもなる
   │  拠点に戻る ／ 送り瓶（使い捨て）で最寄りの拠点に送る
   ▼
[拠点の倉庫]  拠点ごとにある。拠点の段階に応じて広がる
   │  拠点の段階2以上でつながる
   ▼
[夢の回廊（共有網）]  つながった拠点どうしで中身を共有
   └ どの拠点で加工・建築しても、網の中の素材を使える
```

### 細かい仕様
- **重ね方**：同じ素材でも質が違えば別のマス（例：「錆」の質3 と 質5）
- **並べ替え・絞り込み**：質、採れたエリア、mood の要素ごと
- **届け先**：実績の報酬は「最後に寄った拠点」に届き、通知する
- **送り瓶**：使うと手持ちの素材を最寄りの拠点に送る。深いエリアで使って重さが足りなくなると浮かび上がる（[03_depth.md](03_depth.md)）
- **手持ちの容量**：深さ7に必要な重さ以上を持てる大きさにする
- **拠点の個性（拡張の余地・最初は入れない）**：拠点の属性で、特定の素材の保管に特典を付けられるようにしておく（例：月の要素の拠点では「夜露」が劣化しない）

## 上書き層

拠点や建築は **プレイヤーが世界を変えたもの**なので、`content/` の原本は書き換えない。
セーブデータ側に **座標ごとの差分（上書き層）** として記録し、原本の上に重ねて表示する（`src/systems/overlay.ts`）。

- Claude があとでエリアの原本を更新しても、建築は消えない
- 原本の変更とぶつかった部分だけ、検証ツールで知らせる
- **建築は拠点だけ**、**破壊は揺らぎ区域だけ**（揺らぎ区域の破壊跡は、その回の滞在の間だけ残る）
- 閲覧者用の「自分の夢」も同じ上書き層の仕組みで実現する（[09_editor_and_publishing.md](09_editor_and_publishing.md)）
