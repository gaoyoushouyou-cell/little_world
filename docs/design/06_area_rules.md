# 06 エリア規則と能力の層

ジャンプキング型の縦型エリアや、ゼルダ型の戦闘などを個別に作り込まず、
**エリアに付け外しできる「規則」というプラグイン**として足す（`src/plugins/rules/`、1種類1ファイル）。

```jsonc
// area.json
{ "id": "tower_of_falling_dreams",
  "view": "side",
  "depth": 4,
  "rules": [
    { "type": "charge_jump", "maxPower": 12, "airControl": false },
    { "type": "vertical_camera", "showHeight": true },
    { "type": "no_checkpoint" }
  ],
  "effectPolicy": { "disable": ["balloon", "umbrella"] },
  "madnessPolicy": { "reject": ["control_flip"] }
}
```

## 規則の差し込み口

| 差し込み口 | 例 |
|---|---|
| 入力 | 長押しで溜めてジャンプ、空中では操作できない |
| 物理 | 壁で跳ね返る、落下距離に上限がない |
| カメラ | 縦方向だけ追う、上の階層へ一気に切り替える |
| 能力 | 剣を振る、盾を構える |
| 体力と被弾 | このエリアの中でだけ HP がある |
| HUD | 高さメーター、HP のハート（UI 部品の表示条件で出す） |
| 入るとき・出るとき | 能力を一時的に付与し、出たら外す |

## 枠の占有と衝突

- 各規則は「操作」「カメラ」「体力」などのどの枠を占有するかを申告する
- 同じ枠を取り合う規則の組み合わせは、検証ツールが警告する
- 規則は `effectPolicy`（封じるエフェクト）と `madnessPolicy`（受け付けない狂い）をエリアに要求できる
- 到達性チェッカーは封じられたエフェクトを考慮する（塔の中で風船を封じたとき、塔の中のかけらが風船を前提にしていたら警告）

## 能力の層

エフェクトもエリア規則も、最終的には **プレイヤーに能力を足したり外したりするもの**として扱う。

```
基本能力（歩く・ジャンプ）
 ＋ エフェクトで得た能力（浮く、逆さになる…）
 ＋ エリア規則で得た能力（溜めジャンプ、剣…）
 − エリアで封じられた能力
 = そのエリアで実際に使える能力
```

計算は `src/systems/abilities.ts`、能力の定義は `src/plugins/abilities/`。

## ゼルダ型の戦闘

- 住人に「戦闘」部品を足す（HP、攻撃、当たり判定、ノックバック、落とすもの）
- 戦闘規則があるエリアでだけ HP が表示され、追跡者を倒せる（夢の中で、その場所でだけ急に武器が手に入る感覚）
- 倒すと素材や通貨を落とす
- 負けたときは入口に戻り、深さに応じて素材が残り香になる（[03_depth.md](03_depth.md)）

## ジャンプキング型の縦型エリア

- 溜めジャンプ、空中で操作できない、チェックポイントなし、縦に追うカメラ、高さメーター
- 落下は「負け」ではない（素材は失わない）
- 理不尽にならないよう、左右反転などの狂いは `madnessPolicy` で受け付けない

## 今後足せる規則の例

潜入（暗がりに隠れる）、倉庫番型の箱押し、強制スクロール、時間のループ（30秒ごとにエリアが巻き戻る）、
リズム（拍に合わせないと床が消える）、釣り、見下ろし型のシューティング、採掘（揺らぎ区域で使う）。
