## 実装の段階（案）

UI は各段階で必要な分を作り、段階8で仕上げる。各段階の終わりに組み込みブラウザで動作を確認する。

| 段階 | 内容 |
|---|---|
| 1. 基盤 ✅ | Vite + TypeScript + Phaser の雛形、スキーマ、プラグインの自動登録、エリアの読み込み、横 / 見下ろしの移動と自作物理、端の接続とワープ、パララックス（レイヤー：gradient / stars / silhouette / particles / tiles / fog）、サンプルエリア4つ |
| 2. アセットの流れ（一部済み） | ✅ `import-art` ツール（scan / build / preview。切り抜き・原寸化・減色・背景の除去・コマ）、✅ 置いた物（`content/objects/` と `entities.json`。当たり判定・前後の並び・重力に合わせた向き）、✅ inbox の素材をタイル 33 枚・スプライト 49 個に加工して試作版の4エリアに使用、✅ 人物の向き（`walk_down` などを選び、なければ `_right`・向きなしへ戻る）と旅人のプレイヤー（Designer (12) から待機・歩き×3方向）。残り：パレット（mood での差し替えの土台）、背景画像のレイヤー、`new-area` / `validate` ツール、チャットからエリアを足す手順の確立 |
| 3. 作者エディタと地図（一部済み） | ✅ モザイク地図（プレイヤー用）。残り：開発サーバーの保存口、地図エディタ、エリアエディタ、種 |
| 4. 中核の仕組み | 条件・きっかけ・動作、mood、世界のフラグ、夢のかけら、エフェクトの木（取り消し含む）、`reachability` ツール |
| 5. 深さと脅威 | 深さの表、狂いのシェーダー（色は変えない）、住人の部品、追跡者、捕まる処理、沈み、揺れるかけら |
| 6. エリア規則と戦闘 | 規則のプラグイン、能力の層、ジャンプキング型・戦闘、残り香 |
| 7. 資源と拠点（一部済み） | ✅ 素材、手持ちと倉庫と夢の回廊、揺らぎ区域の素材、拠点化と段階1・2、眠る・拠点どうしの移動、セーブ、建築モードの段階 A（家具・置く／しまう・上書き層・持ち物の強化）・段階 B（置ける箱）・段階 C（作業台とレシピ）。残り：建築の段階 D（エフェクトの木）、通貨、送り瓶、段階3・4 |
| 8. UI の仕上げ | メニュー全体、実績と夢日記、アクセシビリティ、ユーザビリティテスト（5段階） |
| 9. 公開 | GitHub Pages への自動公開、自分の夢、セーブの書き出し・読み込み |

開発の地図帳（[14_dev_atlas.md](14_dev_atlas.md)）は本編の段階と並行して進める：✅ P0（エリア・境界の口・出入口・ワープの検査と MindBloom での表示）。P1（計画ノード）は今すぐ作れる。P2（条件・球の解析）は段階4と同時、P3 は段階5以降。
