# 05 住人と脅威

## 住人は部品の組み合わせ

住人は4つ（戦闘エリアでは5つ）の部品を組み合わせて作る。部品は1つずつ追加でき、組み合わせで種類が増える。

| 部品 | 例 | 置き場所 |
|---|---|---|
| 動き方 | 止まっている、徘徊、追いかける、プレイヤーの動きを3秒遅れで真似る、見ていない間だけ動く | `src/plugins/movements/` |
| 感じ取り方 | 視界、足音、mood、距離 | `src/plugins/` 内の感知 |
| 反応 | 逃げる、近づく、消える、mood を変える、ワープさせる | 動作（actions） |
| 不自然な見せ方 | 下記 | `src/plugins/presentations/` |
| 戦闘（任意） | HP、攻撃、当たり判定、ノックバック、落とすもの | `src/plugins/combat/` |

```jsonc
// content/inhabitants/delayed_mimic.json
{ "id": "delayed_mimic",
  "sprite": "pale_child",
  "movement": { "type": "mimic", "delay": 3.0 },
  "presentation": [ "no_shadow", { "type": "frame_stutter", "fps": 3 } ],
  "react": { "onTouch": { "action": "warp", "to": "random_visited" } },
  "requires": { "mood": { "color": "white" } } }
```

## 不自然さを強調する見せ方

- 歩く動作がないまま滑るように移動する
- 自分だけコマ数が極端に少ない、または多い
- 影がない、または影だけが別の方向を向いている
- 遠景のレイヤーにいるのに手前の物に触れる（奥行きが合っていない）
- いつもカメラのほうを向いている
- 縦横の比率が少しだけおかしい
- 一定の周期で一瞬だけ別の姿に化ける
- 近づくとドットが粗くなる（解像度が合わない）
- 何もない方向をじっと見つめていて、その先には何もない

## 追跡者（バックルーム的な要素）

追跡者も住人の一種。

- **意味の分からない規則で動く**：見ていると動かない、背を向けると近づく、照明がちらつくたびに瞬間移動する。理由は説明しない
- **ねじれた空間**：同じ廊下を3回抜けるとレイアウトが変わる、戻ると来た道がない、手続き生成で終わらない部屋
- **追い方**：見下ろしエリアではタイル上の経路探索（A*）、横エリアでは画面外からの追い上げと足音で圧をかける
- 深さ5以上で追跡が始まり、7では複数になる（[03_depth.md](03_depth.md)）
- mood で出現を制御できる（例：緑のときは現れない）
- **追跡者は普段は倒せない**。戦闘規則があるエリアの中でだけ倒せる
- **追跡者はエリアの境界を越えない**。越える種類の追跡者は、戦闘エリアでは姿を変えて逃げる（倒し放題を防ぐ）
- 拠点には入れない（拠点は完全な安全地帯）

## 落ち着く側と不穏な側の切り替え

- 「mood」という言葉は20通りの世界の状態（[02_mood.md](02_mood.md)）だけを指す。落ち着く / 不穏といったエリアの雰囲気は、深さ・規則・住人・音で作る
- 落ち着いたエリアの片隅に、少しだけずれた扉を置く。そこから不穏なエリアに入ると、音と照明が少しずつ変わっていく

## 捕まる・負ける

| 出来事 | 起きる場所 | 結果 | 素材 |
|---|---|---|---|
| 追跡者に捕まる | 戦闘規則のないエリア | 訪れたことのあるエリアのどこかへ飛ばされる | 深さに応じて **その場で失う** |
| 戦闘で負ける | 戦闘規則のあるエリア | そのエリアの最後に入った入口に戻る | 深さに応じて **残り香** になる |

詳細は [03_depth.md](03_depth.md)。どちらの場合も、揺れるかけらは元の場所に戻る。
