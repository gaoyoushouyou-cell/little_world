# 04 進行：夢のかけら・エフェクト・実績

## 進行の流れ

```
かけらを集める → 起点（ベッドの部屋）でエフェクトを解放
  → 前は届かなかった場所に行ける → さらにかけらが手に入る
```

最初は届かない場所にあるかけらも、別のエリアでエフェクトを解放して戻ってくれば取れる（メトロイドヴァニア型）。

## 夢のかけら

```jsonc
// content/areas/inverted_aquarium/fragments.json
[
  { "id": "aquarium_ceiling", "pos": [40, 3],
    "requires": { "effect": "upside_down" } },
  { "id": "aquarium_deep_1", "pos": [88, 30], "value": 1,
    "requires": { "all": [ { "effect": "fish" }, { "mood": { "element": "moon" } } ] } }
]
```

- **ID は一度決めたら変えない・消さない**（セーブデータは ID で記録する）
- 難しい（深い）エリアほど、かけらの数か `value` を増やす
- 揺らぎ区域のかけらも ID で記録し、一度取ったら出なくなる

### かけらの見た目とレア度（決定 42）
- かけらの見た目は 10 種あり、**レア度**で使い分ける。スプライトは `shard_<名前>`（止まった姿）と `shard_<名前>_spin`（回転）
- レア度の順（仮。低い → 高い）：はじまり `beginning` → やすらぎ `calm` → ぬくもり `warmth` → しずけさ `silence` → きぼう `hope` → かなしみ `sorrow` → つながり `bond` → ちえ `wisdom` → いのち `life` → めざめ `awakening`
- レア度と `value`・深さの対応はまだ決めていない（[13_open_questions_and_roadmap.md](13_open_questions_and_roadmap.md)）

### 揺れるかけら
- **深さ4以上で手に入れたかけらは「揺れるかけら」**として持ち運ぶ状態になる
- **どこかの拠点（ベッドの部屋＝拠点0を含む）にたどり着くと確定**し、自分のものになる
- 確定前に戦闘で負けるか追跡者に捕まると、かけらは **元の場所に戻る**（なくならないので取り直せる）
- 深さ3以下のかけらは取った時点で確定

## エフェクトの木（B 案）

- 起点のベッドの部屋にある「エフェクトの木」で、**かけらを消費して好きなエフェクトを選んで解放**する。木は世界に 1 本だけで、拠点のどこへでも移せる（決定 57）
- エフェクトごとに、必要なかけらの数と前提となるエフェクトを設定できる
- **ベッドでいつでも柔軟に取り消せる**（何度でも、一部だけでも）。取り消すと消費したかけらが戻る
  - これにより「道を開かないエフェクトにかけらを使い切って詰む」ことがなくなる
- エリアを足すときは、木に枝を足す
- 定義は `content/world/effect_tree.json`、各エフェクトのデータは `content/effects/<id>.json`

### エフェクトの候補（たたき台）
| エフェクト | 効果 |
|---|---|
| 風船 | 重力が軽くなる |
| 逆さ | 重力が反転する |
| 傘 | ゆっくり落ちる |
| 小人 | すき間を通れる |
| 魚 | 霧の中を泳ぐ |
| ランタン | 暗闇を照らす |
| 眼鏡 | 隠れたレイヤーが見える |
| 止まった時計 | 追跡者が止まる |

エフェクトはエリアの物理パラメータや能力を書き換える仕組み（[06_area_rules.md](06_area_rules.md) の能力の層）。
既存の仕組みで表せるものはデータだけで、表せないものは `src/plugins/effects/` に処理を足す。

### 表記の区別
かけらを消費するので「残り」の意味が二通りある。記号と言葉を分ける。
- 地図：**未取得** `◇ 1/3`
- エフェクトの木：**手持ち** `◆ 4`

## 世界のフラグ

「赤い部屋で座った」などの状態を記録し、遠く離れたエリアを変化させる。
エリア同士を地図上の位置と関係なくつなげられる。条件 `{ "flag": "..." }` で参照する。

## 実績と夢日記

実績を1つ解除すると、日記に1ページ増える。

```jsonc
// content/achievements/first_red_moon.json
{ "id": "first_red_moon",
  "when": { "all": [ { "mood": { "color": "red", "element": "moon" } }, { "inArea": "rust_garden" } ] },
  "diary": "錆びた庭で、月が赤く熟れていた。誰も収穫しに来ない。",
  "hidden": true,
  "page_art": "diary/rust_moon",
  "reward": { "items": [ { "id": "rust", "quality": 3, "count": 5 } ] } }
```

- きっかけ：初めて到達した、特定の mood で見た、追跡者から逃げ切った、など
- 隠し実績は解除されるまで日記のページが塗りつぶされている
- 日記の文章は事実ではなく印象を書く
- **実績の報酬で素材が手に入る**。報酬は「最後に寄った拠点」の倉庫に届き、通知される
- エリアを作るたびに、そのエリアの日記ページを 1〜3 枚作る

## 到達性の保証（詰み防止）

`tools/reachability.ts` が、地図・出入口・条件・エフェクトの木を読み込み、
手に入るエフェクトと mood の全組み合わせを探索して、次を一覧にする。

- 取れないかけら
- 戻れなくなる一方通行
- どの組み合わせでも開かない扉

探索に含める要素：

- エフェクト（解放の前提関係を含む）
- mood（20通り）と、それを変える動作がどこにあるか
- エリアごとのエフェクトの封じ方（`effectPolicy`）
- 沈み：「重さ N 以上を持てる」を能力として扱い、それより浅いエリアの素材で重さ N を集められるかを判定する
- 揺らぎ区域の生成器が保証する道

**不変のルール**：

- **拠点を1つも作らなくても、全部のかけらを取れる**（拠点の mood 固定やワープは前提にしない）
- 新しいエリアを足したら、必ずこのチェックを実行してから報告する
