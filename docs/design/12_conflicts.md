# 12 矛盾の一覧と解決

議論で洗い出した矛盾と、その解決。すべて決定済み（推奨どおり、または議論で変更したもの）。

## A：設計の前提に関わるもの

| # | 矛盾 | 解決 |
|---|---|---|
| A-1 | B 案（選んで解放）では、道を開かないエフェクトにかけらを使い切ると詰む | **ベッドで柔軟に取り消せる**（何度でも・一部だけでも）。かけらが戻る |
| A-2 | 拠点の mood 固定やワープはプレイヤー次第なので、到達性の前提にできない | **拠点を1つも作らなくても全部のかけらを取れる**ことを不変のルールにする |
| A-3 | 負けても入口に戻るだけでは、深さの危険と報酬の天秤が成り立たない | 深さ4以上で手持ちの素材を失う（戦闘は **残り香**、捕まると **その場で失う**）。送り瓶で危険を管理する |
| A-3' | 手ぶらで深いエリアに挑めば失うものがない／かけらは危険なしで取れる | **沈み**（深さ4以上は重さが必要）と **揺れるかけら**（拠点に持ち帰って確定）を追加 |
| A-4 | 揺らぎ区域とずっと残る要素（かけら・実績）の扱い | かけらは ID で記録して一度だけ。生成器がかけらへの道を保証。揺らぎ区域は拠点にできない |
| A-5 | 公開版のエディタで全体が見えるとネタバレ。閲覧者が作った場所と作者の追加が重なる | 閲覧者用は **自分の夢** として本編から完全に分ける |

## B：遊びの質に関わるもの

| # | 矛盾 | 解決 |
|---|---|---|
| B-1 | 「意味も分からないまま」と「使いやすい UI」 | 仕組みは明快に、夢の中身は説明しない。日記は印象を書く |
| B-2 | 拠点が増えるほど安全地帯が増え、恐怖が薄れる | 拠点は **完全な安全地帯**。数は費用の重さ（量と質）で抑える |
| B-3 | 追跡者が戦闘エリアまでついてくると倒し放題 | 追跡者はエリアの境界を越えない。越える種類は戦闘エリアで姿を変えて逃げる |
| B-4 | 縦型の塔で左右反転などの狂いが起きると理不尽 | エリア規則が受け付けない狂いを申告する（`madnessPolicy`） |
| B-5 | 深さで狂いが決まると、深い場所に落ち着くエリアを作れない | エリアごとに狂いを抑制できる。その場合、深さは素材の質にだけ効く |
| B-6 | 揺らぎ区域で素材を取り放題 | 質の上限は深さで決まる。足りなければ連続で採るほど出にくくする |
| B-7 | 拠点間ワープが迷い込む探索を壊す | 拠点間ワープは段階2から。地図上の線も夢のワープとは別の見た目 |
| B-8 | 深い狂いの演出と光過敏 | 起動時に注意を出す。点滅の抑制では **動き・音** で代わりに不気味さを出す（色は使わない） |

## C：実装上の注意点

| # | 矛盾 | 解決 |
|---|---|---|
| C-1 | パレットを触る仕組みが重なる（エリアの色・mood・深さ） | **深さの狂いは色を変えない**。色はエリアの基本パレット → mood の順にだけ適用 |
| C-2 | mood の色の仕掛けと色覚の多様性 | 色ごとに記号と模様 |
| C-3 | 黒の mood と暗いエリアが重なると何も見えない | 輪郭を光らせるなど、見え方の下限を決める |
| C-4 | 視点や重力が違うエリアの境界で、空中や天井に出る | 一番近い安全な足場に出現。地図エディタで警告 |
| C-5 | 端でつながるエリアは入口が複数 | 負けたら **最後に入ってきた入口** に戻す |
| C-6 | 地図のモザイクと、変化する要素（mood で現れる橋・揺らぎ区域・建築） | 原本の基本のタイルだけを描く。揺らぎ区域はノイズ、拠点は印 |
| C-7 | エリアの重なりで地図が読めない | 重なった部分を切り替えて表示 |
| C-8 | 今のエリアと隣だけを読み込むのに、遠くに及ぶ状態がある | エリアをまたぐ状態はすべて `src/systems/` が持つ |
| C-9 | かけらの「残り」が未取得か未使用かまぎらわしい | 地図は「未取得 ◇」、エフェクトの木は「手持ち ◆」 |
| C-10 | 公開版のセーブはブラウザ頼み | 書き出し・読み込みを付ける |
| C-11 | エリアでエフェクトを封じると、その中のかけらが取れなくなる | 到達性チェッカーが `effectPolicy` を考慮する |

## 議論の途中で見つかったもの

| # | 矛盾 | 解決 |
|---|---|---|
| D-1 | 最初の案では「捕まると知らないエリアへ飛ばされる」だったが、戦闘で負けたら入口に戻る決定と別物 | 捕まる（戦闘規則なし）→ **訪れたことのあるエリア** へ飛ばす。負ける（戦闘規則あり）→ 入口へ |
| D-2 | 捕まると別のエリアに飛ばされるので「エリアを出ると残り香が消える」とぶつかる | 捕まった場合は残り香にせず **その場で失う** |
| D-3 | 送り瓶で拾うたびに送れば危険がない | 送り瓶で重さが足りなくなると浮かび上がる |
| D-4 | 負けて素材を失うと重さが減り、浮かび上がって残り香を取りに戻れない | 残り香も同じエリアにある間は自分の重さとして数える |
| D-5 | 負けた直後に揺らぎ区域が作り直されると残り香が消える | 負けて入口に戻るときは作り直さない |
| D-6 | 点滅の代わりに色を使う案が、深さで色を変えない決定と矛盾 | 動き・音に差し替え |
