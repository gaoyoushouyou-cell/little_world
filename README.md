# little world

ドットで描かれた、夢日記のような乱雑な世界を歩くゲーム。
エリアごとに視点（横 / 見下ろし）や物理（重力の向き、時間の速さ、ループする端）が変わる。

> 開発中（段階1：基盤）。設計は [docs/design/](docs/design/README.md) を参照。

## 遊び方（開発版）

```
npm install
npm run dev
```

ブラウザで http://localhost:5173 を開く。

| 操作 | キー |
|---|---|
| 移動 | 矢印キー / WASD |
| ジャンプ（横視点） | Space / Z |
| 扉・ワープに入る、調べる（ベッド・箱・椅子） | E / X / Enter |
| 持ち物 | I（T 並べ替え、H 半分に分ける、拠点の中では Q で倉庫へまとめる） |
| 手作り（作業台そのものなど） | C（持ち物の画面からも）。置いた作業台は E で調べると、作業台のレシピも作れる |
| 建築モード（拠点の中だけ） | B（矢印 予告を動かす、Q / E 家具を選ぶ、Enter / Space 置く、X しまう、R 左右反転、Esc 戻る） |
| 地図 | M |
| 画面を閉じる | Esc / Backspace / X |
| デバッグ表示 | `（バッククォート） |

## 開発

```
npm test           # テスト
npm run typecheck  # 型検査
npm run build      # 公開用ビルド
npm run atlas      # 開発の地図帳の解析（到達できないエリア・戻れないエリアなどを検査）
```

ゲームのデータはすべて `content/`（JSON）、コードは `src/`。
新しいレイヤーの種類などは `src/plugins/<種類>/` に1ファイル置くだけで登録される。
