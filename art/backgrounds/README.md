# backgrounds/ — 背景（パララックス）

エリアの奥や手前に重ねる、遠景・中景・前景の絵。

## 描き方

- **背景のセットごとにフォルダ**を作る
  ```
  backgrounds/
    jellyfish_city/
      far.png    ← 一番奥（ゆっくり動く）
      mid.png    ← 中景
      near.png   ← 手前（プレイヤーより前を速く流れる）
      jellyfish_city.md
  ```
- 枚数は自由です（`far1.png`、`far2.png` のように増やしてもよい）
- **横につなげて繰り返す**ので、左端と右端がつながるように描くときれいに流れます
- 画面の大きさは **480×270**。高さはこれを目安に、幅は 480 以上が扱いやすいです
- 空など一面の部分は透明にしてかまいません（後ろのグラデーションが見えます）

## メモに書くとよいこと

- どのエリアに使うか
- 奥行きの順番、どれくらいの速さで流れてほしいか
- 自動で流れてほしいか（雲・水の流れなど）

## 加工のされ方

大きな絵はドット絵の文字データにはせず、色数を整えた PNG として `content/assets/images/` に置き、
エリアの `layers` から背景レイヤーとして使います。
