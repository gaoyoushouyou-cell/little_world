# objects/ — エリアに置く物

家具・扉・ベッド・灯り・像・拠点の核など、タイルより大きかったり、触れたり調べたりできる物。

## 描き方

- 1つの物 = 1枚（例：`red_chair.png`、`bed_top.png`、`door_blue_side.png`）
- 大きさは自由。**16 の倍数**（16×32、32×32 など）だとエリアの格子に置きやすくなります
- 動く物（揺れる灯り、開く扉など）は、同じ大きさのコマを横一列に並べる
- 置いたときに床に接する面が、画像の一番下に来るように描く

## 視点

| 視点 | 描き方 | ファイル名 |
|---|---|---|
| 横 | 真正面から見た姿（正面だけ） | `<名前>_side.png` |
| 見下ろし | 斜め上から見下ろした姿（上の面と正面。左右の側面は見せない） | `<名前>_top.png` |
| どちらでも（夢のずれ） | **等角投影（斜め45°の立体）でもよい** | `<名前>.png` |

- 等角投影の物は、床に接する部分（ひし形）の一番下の点を、画像の一番下・左右の中央にそろえてください
- 当たり判定の範囲に床の影（接地影）を付けると、どこにぶつかるかが分かりやすくなります

## メモに書くこと

**当たり判定は必ず書いてください**（等角投影の物も、そうでない物も）。

```
当たり判定（見下ろし）: 横 2 マス × 奥行き 1 マス（画像の下端中央が基準）
当たり判定（横）: 固い・高さ 2 マス（上に乗れる）
```

- 1マス = 16 ドット
- 見下ろし：床の上でぶつかる範囲。ぶつからない物は「なし」
- 横：「なし（背景の飾り）」「固い（上に乗れる）・高さ 〇 マス」「上だけ乗れる（下から通り抜けられる）」のどれか
- 四角でない範囲は、マス目の図で書いてもかまいません（`#` がぶつかるマス）

そのほかに書くとよいこと：

- 調べたり座ったりできるか、そのとき何が起きてほしいか
- 建築モードで置ける家具にしたいか

## 加工のされ方

`content/assets/sprites/<id>.json` に変換されます。家具として使う場合は `content/furniture/` からも参照します。
当たり判定は、メモの内容をもとにデータに書き込みます。
