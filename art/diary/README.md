# diary/ — 夢日記の挿絵

実績を解除したときに増える、夢日記のページに添える小さな絵。

## 描き方

- 1ページ = 1枚（例：`rust_moon.png`）
- 大きさは自由。目安は **64×48** 前後
- ファイル名は実績の ID にそろえると対応がわかりやすくなります（例：実績 `first_red_moon` → `first_red_moon.png`）

## メモに書くとよいこと

- どの実績・どの場面の絵か
- 日記の文章の希望（なければ Claude が印象を書きます）

## 加工のされ方

色数を整えた PNG として `content/assets/images/diary/` に置き、実績の `page_art` から使います。
