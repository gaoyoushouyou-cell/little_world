# items/ — アイテムのアイコン

素材（錆・鱗・羽根…）、通貨、夢のかけら、送り瓶など、持ち物や地図に表示するアイコン。

## 描き方

- **1つ = 16×16**（例：`rust.png`、`feather.png`、`dream_fragment.png`）
- 地面に落ちている姿を別にしたい場合は `_world` を付けてください（例：`rust_world.png`）
- 素材の質の違いを絵で表したい場合は `_q1`〜 を付けてください（例：`rust_q3.png`）。なければ色の明るさなどで表します

## メモに書くとよいこと

- 何の素材か、どのエリアで採れるか
- 重さの感じ（沈みのための重りになる）

## 加工のされ方

`content/assets/sprites/<id>.json` に変換され、アイテムの定義（`content/items/`）から使われます。
