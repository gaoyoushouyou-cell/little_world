# tiles/ — タイル

地面・壁・床・装飾など、エリアの格子に並べる 16×16 のタイル。

## 描き方

- **1枚 = 16×16**（例：`night_stone.png`）
- 何枚かまとめて描く場合は、16×16 の格子に並べた1枚の画像でもかまいません（例：`aquarium_set.png`）
  - その場合はメモ（`aquarium_set.md`）に、どのマスが何のタイルかを書いてください
- 透明な部分があるタイルは、床などの上に重ねる装飾として使います（花・草・ひびなど）

## メモに書くとよいこと

- **固いか**：当たり判定があるか（壁・地面）、通り抜けられるか（床・装飾）
- 使いたいエリアや雰囲気
- 隣に同じタイルが並んだときの見え方の希望（つなぎ目を目立たせたくない、など）

## 加工のされ方

`content/assets/tiles/<タイルセット>.json` の1タイル（パレット + 文字グリッド）に変換され、`source` に元の画像が記録されます。
