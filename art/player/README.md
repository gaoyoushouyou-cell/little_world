# player/ — プレイヤー

プレイヤー（夢を見ている子）の姿とアニメーション。

## 描き方

- アニメーション × 向きごとに1枚。同じ大きさのコマを **横一列** に並べる
  ```
  player/
    idle_down.png    ← 立ち止まり・正面
    idle_up.png      ← 立ち止まり・背中
    idle_right.png   ← 立ち止まり・右向き
    walk_down.png    ← 歩き・正面
    walk_up.png      ← 歩き・背中
    walk_right.png   ← 歩き・右向き
    idle_side.png    ← （任意）横視点の真横の姿
    walk_side.png    ← （任意）
  ```
- **左向きは右向きの左右反転で作ります**。左右で形が違う場合だけ `_left` も描いてください
- **横視点の姿（`_side`）がなければ、右向き（`_right`）をそのまま使います**
- ほかに欲しい動き（`jump_side.png`、`sit_down.png` など）があれば足してください
- いまの仮の姿は **12×22** ドット（当たり判定は横 10 × 縦 20、見下ろしでは足元 10 × 8）
  - 大きさを変えたい場合はメモに書いてください。当たり判定も合わせて調整します
- 全部の向きで、大きさ・足元の位置・コマ数をそろえてください（足元がコマの一番下）

## 加工のされ方

`content/assets/sprites/dreamer.json`（パレット + コマごとの文字グリッド）に変換されます。
