# effects/ — エフェクト

夢のかけらで解放するエフェクト（風船、逆さ、傘、魚…）のアイコンと、使ったときのプレイヤーの姿。

## 描き方

- **エフェクトごとにフォルダ**を作る
  ```
  effects/
    balloon/
      icon.png         ← エフェクトの木に表示するアイコン（16×16）
      idle_down.png    ← 使っているときの姿（プレイヤーと同じ大きさのコマを横一列）
      walk_down.png
      idle_right.png
      walk_right.png
      balloon.md
  ```
- 姿はプレイヤー（`art/player/`）と同じ大きさ・足元の位置・コマ数で描く
- 向きは **下（`_down`）と右（`_right`）の2方向だけでもよい**。上向きなど足りない向きは、ゲーム側で元の姿のまま表示する。左は右の反転、横視点は右向きで代用

## メモに書くとよいこと

- どんな効果にしたいか（重力が軽くなる、すき間を通れる…）
- 解放に必要なかけらの数の希望

## 加工のされ方

アイコンと姿は `content/assets/sprites/` に変換され、エフェクトの定義（`content/effects/<id>.json`）から使われます。
