# art/ — あなたが描いたドット絵の置き場所

ここは **原画の置き場所** です。描いた PNG を種類ごとのフォルダに入れてください。
Claude はアセットを本格的に作るとき、ここから画像を取り出して加工し、ゲーム用のデータを `content/assets/` に作ります。

```
art/（原画・あなたのもの）  ──加工──▶  content/assets/（ゲームが読むデータ）
```

- **Claude は art/ の中のファイルを書き換えたり消したりしません**（原画はいつでも描き直せるように残します）
- 加工したデータには、元にした原画のパスを `source` として記録します
- 原画を描き直したら、チャットで「art/tiles/〇〇 を描き直した」と伝えてください。加工し直します

## フォルダ

| フォルダ | 入れるもの |
|---|---|
| [tiles/](tiles/README.md) | 地面・壁・床などのタイル（16×16） |
| [player/](player/README.md) | プレイヤーの姿とアニメーション |
| [inhabitants/](inhabitants/README.md) | 住人・追跡者の姿とアニメーション |
| [objects/](objects/README.md) | 家具・扉・ベッド・灯りなど、エリアに置く物 |
| [items/](items/README.md) | 素材・通貨・夢のかけらなどのアイコン |
| [backgrounds/](backgrounds/README.md) | パララックスの遠景・中景・前景 |
| [effects/](effects/README.md) | エフェクトのアイコンと、変身したときの姿 |
| [ui/](ui/README.md) | mood の印・枠・アイコンなどの UI 部品 |
| [diary/](diary/README.md) | 夢日記のページに添える挿絵 |
| [inbox/](inbox/README.md) | どこに入れるか迷ったもの（Claude が仕分けます） |

## 全種類に共通の決まり

絵の体裁（大きさ・色数・陰影・アニメーションの形式など）の詳しい規則は **[PIXEL_STYLE.md](PIXEL_STYLE.md)** にあります。
ほかの AI に描いてもらうときは、その文書をそのまま渡してください。

- **形式**：PNG。背景は透明（画像生成 AI で透明にできないときは #FF00FF の一色塗り）
- **大きさ**：1ドット = 1ピクセルの原寸で描くのがいちばん確実です
  - 拡大して描いた場合は、ファイル名の最後に倍率を付けてください（例：`stone@4x.png`）。取り込むときに原寸に戻します
- **ぼかしなし**：アンチエイリアス（縁のぼかし）は付けない
- **色**：1枚 16 色以内（タイル・アイコンは 8 色以内を推奨）。取り込むときに使われている色からパレットを作ります
  - パレットの色は mood（色の状態）で差し替えるので、色数が少なく明暗の段がはっきりしているほど扱いやすくなります
  - なじみやすい基本パレットは [PIXEL_STYLE.md](PIXEL_STYLE.md) にあります
- **ファイル名**：英小文字・数字・`_` を推奨（例：`melting_clock.png`）。そのままゲーム内の ID になります
  - 日本語の名前でも大丈夫です。その場合は取り込むときに Claude が ID を決め、加工したデータに記録します
- **メモ（任意）**：同じ名前の `.md` を置くと、意図を伝えられます（例：`melting_clock.md` に「触ると mood が赤になる時計」）
- **アニメーション**：同じ大きさのコマを **横一列** に並べた1枚の画像にします。コマの大きさはメモかファイル名で伝えてください（例：`walk_down_17x24.png`）
- **視点**：横視点は正面から、見下ろしは斜め上から（上の面と正面）描きます。家具などの物は、夢のずれとして等角投影でもかまいません。片方の視点でしか使わない物は `_side` / `_top` を付けます
- **向き**：人物は見下ろし用に下・上・右の3方向を描きます（左は反転、横視点は右向きで代用）
- **当たり判定**：物はメモに必ず書いてください（書き方は [PIXEL_STYLE.md](PIXEL_STYLE.md) の 2.3）
