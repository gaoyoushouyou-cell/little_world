# inhabitants/ — 住人・追跡者

夢の住人や、追いかけてくる存在の姿。

## 描き方

- **住人ごとにフォルダ**を作り、その中にアニメーションを1枚ずつ置く
  ```
  inhabitants/
    pale_child/
      idle_down.png
      walk_down.png
      walk_up.png
      walk_right.png
      pale_child.md   ← メモ
  ```
- アニメーションは、同じ大きさのコマを横一列に並べる
- 足元がコマの一番下に来るように描く
- **向き**：見下ろしのエリアで歩き回るなら、下・上・右の3方向（左は反転、横視点は右向きで代用）。止まっているだけなら `idle_down.png` の1枚でよい
- 全部の向きで、大きさ・足元の位置・コマ数をそろえる

## 不自然さについて

不自然さ（コマ数が極端に少ない、影がない、比率がおかしい、など）は、絵だけでなく動かし方でも出せます。
メモに「どう不自然にしたいか」を書いてもらえれば、絵と動きの両方で表現します。

## メモに書くとよいこと

- どんな存在か、どこに現れるか
- どう動くか（止まっている、真似をする、見ていない間だけ動く…）
- 追いかけてくるか

## 加工のされ方

`content/assets/sprites/<id>.json` に変換され、住人の定義（`content/inhabitants/<id>.json`）から使われます。
