# ui/ — UI 部品

画面に重ねて表示する部品。

- mood の印（5色・4要素それぞれの記号）
- HP のハート、高さメーター
- メニューやウィンドウの枠
- 操作のヒントに使うキーの絵
- 地図の印（拠点・ワープ）

## 描き方

- 1つ = 1枚（例：`mood_red.png`、`element_moon.png`、`heart_full.png`）
- **枠**は、角と辺を伸ばして使うので、9つに分けやすいように描いてください（四隅・四辺・中央）。メモに角の大きさを書いてください（例：「角は 4×4」）
- 色覚への配慮のため、mood の印は **色だけでなく形でも区別できる**ようにしてください

## 加工のされ方

色数を整えた PNG として `content/assets/images/ui/` に置き、UI から使います。
